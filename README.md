# תזכורות

אפליקציית תזכורות בעברית שמותקנת בטלפון ובמחשב (PWA), עם התראות שקופצות גם כשהאפליקציה סגורה.

## מה יש בה
- תזכורות חד פעמיות וחוזרות: כל X דקות/שעות/ימים, ימים נבחרים בשבוע, ימים נבחרים בחודש (כולל יום אחרון), שנתי, ושנתי לפי תאריך עברי. אפשר לקבוע תאריך סיום.
- ימי הולדת עם חישוב גיל, לפי תאריך לועזי או עברי, עם תזכורת מוקדמת.
- נודניק שחוזר עד שמסמנים ״בוצע״, ודחייה (5 דק׳ עד ״מחר בבוקר״), גם מתוך ההתראה עצמה.
- 16 צלילים מקוריים לבחירה עם השמעה לדוגמה, עוצמה, וצליל חוזר עד לחיצה.
- מסך בית בסגנון ווידג׳טים, לוח שנה עם תאריך עברי, חגים וראשי חודשים, חיפוש וקטגוריות.
- הוספה מהירה בטקסט חופשי או בקול (״להתקשר לאמא מחר ב-9״), רשימות משנה, תמונה מצורפת, הודעה קולית מוקלטת (voice-note.js).
- מצב כהה, 7 צבעים, טקסט גדול, נעילה בקוד.
- גיבוי ושחזור (קובץ JSON) להעברה למכשיר חדש, ייצוא ליומן (ICS) וכפתור ״הוספה ליומן Google״.
- כפתור התקנה בתוך האפליקציה, עם הוראות מותאמות לאייפון, אנדרואיד ומחשב.

## איך ההתראות מגיעות כשהאפליקציה סגורה
התזכורות נשמרות במכשיר (IndexedDB). המכשיר שולח לשרת רק את רשימת המועדים הקרובים (שעה, כותרת והערה) ומנוי Web Push.
השרת (`worker/`) הוא Cloudflare Worker עם Durable Object אחד: שעון מעורר (alarm) מעיר אותו בדיוק בזמן ההתראה הבאה ושולח Web Push מוצפן (RFC 8291, VAPID). cron כל דקה הוא גיבוי.
כשהתראה מגיעה, ה-Service Worker מציג אותה ומרענן את רשימת המועדים בשרת, כך שתזכורות חוזרות ממשיכות לנצח.
מפתחות VAPID נוצרים לבד בפעם הראשונה. אין סודות להגדיר.

מגבלות של הפלטפורמה: באייפון התראות עובדות רק מהאפליקציה המותקנת (iOS 16.4 ומעלה). צליל מותאם מתנגן כשהאפליקציה פתוחה; כשהיא סגורה ההתראה מגיעה עם צליל ההתראות של המכשיר. במחשב הדפדפן צריך לרוץ ברקע.

## פיתוח
```
npm install
npm test          # בדיקות מנוע המועדים והצפנת ההתראות
npx wrangler dev  # הרצה מקומית
```
פרסום: Cloudflare Workers Builds מחובר למאגר. כל דחיפה ל-main מפרסמת (`npx wrangler deploy`).
